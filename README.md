# RecycleChain

Prototype bank sampah digital: setor sampah terpilah, kumpulkan poin, lalu tukar dengan pulsa, voucher, token listrik, atau donasi.

Sampahmu jadi saldo, bukan cuma jadi bau.

## Isi

- `index.html`: halaman aplikasi (Beranda, Setor sampah, Tukar poin, Riwayat, Paket membership)
- `css/style.css`: tampilan
- `js/data.js`: data contoh (tarif poin, jadwal penimbangan, transaksi)
- `js/script.js`: logika aplikasi

Semua poin, reward, dan transaksi adalah data contoh untuk demonstrasi. Tidak ada pembayaran atau pengiriman reward yang sungguhan.
